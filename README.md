# YT AutoPost Studio

Десктопна програма (Windows) та веб-додаток для мультиканального автопостингу й запланованої публікації відео на YouTube через офіційний **YouTube Data API v3**.

Усі API-ключі Google OAuth, зашифровані токени каналів, база даних SQLite та прев’ю зберігаються **локально лише на вашому комп’ютері**.

## Можливості
- **Десктопний режим (Electron + System Tray):**
  - запуск як окрема програма на Windows з іконкою в системному треї для фонової публікації за розкладом;
  - вибір відео та обкладинок **напряму з диска** (без дублювання багатогігабайтних файлів, за бажанням є галочка копіювання у сховище програми);
  - авторизація Google OAuth через ваш системний браузер (з можливістю копіювати посилання для інкогніто/окремих профілів Chrome) та повернення на локальний loopback `127.0.0.1`;
  - збереження всіх даних у `%APPDATA%\yt-autopost-studio` (можна відкрити прямо з Налаштувань).
- **Підключення багатьох каналів із різних Google-акаунтів (OAuth 2.0):** один Google Cloud проєкт для всіх каналів, кнопка копіювання OAuth-посилання для відкриття в інкогніто чи окремому профілі браузера, шифрування токенів у базі даних (`AES-256-GCM`).
- **Повний набір метаданих і галочок YouTube Studio:**
  - відеофайл + кастомне прев’ю (`thumbnails.set`)
  - тайтл, опис, теги, категорія, мова відео/опису, додавання в плейлист каналу
  - **«Не для дітей»** (`selfDeclaredMadeForKids`)
  - **«Це не AI / без синтетичного контенту»** (`containsSyntheticMedia`)
  - **Платна реклама / спонсорство** (`hasPaidProductPlacement`)
  - **Сповістити підписників** (`notifySubscribers`)
  - **Дозволити вбудовування** (`embeddable`), **Публічна статистика** (`publicStatsViewable`), **Ліцензія** (`youtube` / `creativeCommon`)
  - Опція очікування завершення обробки HD перед відкриттям у `public`
- **Пресети авто-галочок:** автоматична підстановка всіх прапорців, категорії, тегів і футера опису при виборі каналу.
- **Запланована публікація:** через вбудований YouTube `publishAt` (предзалив як `private`) або через серверну чергу з індивідуальними слотами розкладу для кожного каналу.
- **Sandbox-режим:** вбудований тестовий канал для повної перевірки інтерфейсу, черги та API-payload без витрати реальної квоти Google.

## Запуск десктопної програми (Windows)

```bash
npm install
npm run desktop:start
```

Збірка `.exe` / інсталятора Windows (`release/`):

```bash
npm run desktop:pack
```

Після збірки у папці `release/` з’явиться:
- інсталятор та портативний `.exe` (`YT AutoPost Studio ... .exe`);
- розпакована папка `win-unpacked/YT AutoPost Studio.exe`.

## Запуск у режимі веб-додатку (розробка / браузер)

```bash
npm run dev
```

- Фронтенд у dev-режимі: `http://localhost:5173`
- Бекенд API та OAuth callback: `http://localhost:3456`

Для локальної збірки веб-версії на одному порту (`3456`):

```bash
npm run build
npm start
```

## Налаштування Google Cloud OAuth
Детальна інструкція вбудована прямо у програму на вкладці **«Налаштування Google API»**.
Для десктопної програми найзручніше створити **OAuth Client ID → Desktop app** (або **Web application** з Redirect URI `http://localhost:3456/api/auth/google/callback`).
